# Weather Lottie animations

Animated Lottie weather icons used by the weather pill, dashboard widget, and
weather page hero. Sourced from [Meteocons](https://github.com/basmilius/weather-icons)
by Bas Milius, distributed via the [`@meteocons/lottie`](https://www.npmjs.com/package/@meteocons/lottie)
package under the [MIT License](https://github.com/basmilius/weather-icons/blob/main/LICENSE).

Style: `fill`. Each file is renamed to the app's canonical animation key
(see `src/lib/weather/lottie-animation.ts`).

| Local file | Meteocons source |
|------------|------------------|
| `clear-day.json` | `fill/clear-day.json` |
| `clear-night.json` | `fill/clear-night.json` |
| `partly-cloudy-day.json` | `fill/partly-cloudy-day.json` |
| `partly-cloudy-night.json` | `fill/partly-cloudy-night.json` |
| `cloudy.json` | `fill/cloudy.json` |
| `fog.json` | `fill/fog.json` |
| `drizzle.json` | `fill/drizzle.json` |
| `rain.json` | `fill/rain.json` |
| `heavy-rain.json` | `fill/extreme-rain.json` |
| `thunderstorm.json` | `fill/thunderstorms.json` |
| `snow.json` | `fill/snow.json` |
| `sleet.json` | `fill/sleet.json` |

To refresh, re-download from `https://cdn.jsdelivr.net/npm/@meteocons/lottie/fill/<name>.json`.
