# Travel world texture

`earth.jpg` is the unmodified Earth texture from the three.js r180 examples:
https://raw.githubusercontent.com/mrdoob/three.js/r180/examples/textures/planets/earth_atmos_2048.jpg

Upstream project and license:
https://github.com/mrdoob/three.js/tree/r180
https://github.com/mrdoob/three.js/blob/r180/LICENSE

The texture is served locally so the world globe does not depend on Google tiles.
Photorealistic city tiles remain a separate Google service with its own runtime attribution.
